# Cinematic V4 — content-first redesign

This pass follows the approved reference direction while keeping the existing data/player architecture intact.

- Removed visible NORRSKEN branding from hero/detail/TV navigation chrome. Internal package/class names are unchanged to avoid risky migration work.
- Mobile chrome is now edge-to-edge: the top bar overlays artwork instead of consuming a black strip.
- Mobile home hero uses substantially more of the width and a tighter vertical composition.
- Mobile bottom navigation is a compact floating dark panel with a restrained active indicator.
- Removed the fixed cyan/green atmospheric wash from the cinematic light field; artwork is intended to provide the visual color identity.
- Movie/series badges are neutral content labels instead of brand/theme labels.
- Existing Shield focus/backdrop behavior, playback, EPG, favorites, history and library logic are preserved.

The generated concept image is a visual target, not a screenshot. Real content/artwork availability still depends on provider/TMDB data.
